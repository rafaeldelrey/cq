# cq

Code-quality snapshots for a repository: 30 collectors (coverage, pyright, ruff, complexity, dead code,
duplication, docstrings, semgrep, dependency hygiene, vulnerabilities, secrets, mutation testing,
AI-slop tools, …), stored as history and reported as trends, plus a PR gate that judges what a
branch adds over its base.

Extracted from `rafaeldelrey/angel-monitor`'s `code_quality/` on 2026-10-17 (angel-monitor#391).
Its history before that date lives there.
